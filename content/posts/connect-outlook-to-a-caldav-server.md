In the past I’ve used [The Hula Projet](http://www.hula-project.org/) as a mail server, but one thing has always lacked in terms of real production readiness in my opinion – Outlook Integration.

<!--more-->

Many Open Source mailservers (including hula) support a protocol called Caldav. You can connect to Caldav servers via several open source calendar like [Sunbird](http://www.mozilla.org/projects/calendar/sunbird/).

The Open Soiurce Outlook Connector Project is a plugin for Outlook that translates the Caldav stream into a format that Outlook can understand.
